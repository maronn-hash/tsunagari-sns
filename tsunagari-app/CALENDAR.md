# 共有カレンダー

PCの広い画面では、右側の上部に小さなカレンダーを常時表示します。予定のある日は点で示し、日付を押すと大きなカレンダーでその日の予定を開きます。右側にも選択日の予定を最大3件表示し、追加分は「ほか○件を見る」から確認できます。月送り・今日への移動・「更新」にも対応しています。

PCの左メニュー、スマートフォンの下部メニューの「カレンダー」からも開けます。幅の狭い画面では右側欄を非表示にして、従来どおりメニューから利用します。

- 月表示で日付を選ぶと、その日の予定を確認できます。
- 「予定を追加」で予定名（80文字以内）、日付、開始・終了時刻、メモ（500文字以内）を登録できます。
- 時刻は日本時間です。開始・終了時刻を両方空欄にすると終日になります。終了時刻は省略できます。
- ログイン済みのメンバー全員が予定を閲覧できます。新規追加は管理者のみ可能で、一般メンバーには追加ボタンを表示しません。編集・削除できるのは登録した本人だけです。更新前に一般メンバーが作成した予定は残り、その本人が引き続き編集・削除できます。
- 登録済みの予定を押して詳細を開きます。削除時は確認を表示します。
- 「今日」で当日に戻り、「再読み込み」で他のメンバーの変更を取得できます。
- 予定はSNSのデータベースに保存され、同じ保存先で再起動すれば残ります。
- 繰り返し予定、複数日にまたがる予定、通知、外部カレンダー連携は含みません。

## 更新手順

1. SNSを Ctrl+C で停止します。
2. 使用中の data-external-trial フォルダーをバックアップします。別の保存先を設定している場合は、そのフォルダーをバックアップします。
3. ZIPを展開し、中の tsunagari-app のファイルを使用中の同名フォルダーへ上書きコピーします。既存のデータフォルダーは削除しないでください。
4. start-sns.cmd で起動します。Node.js版はカレンダー用テーブルを自動追加します。
5. ブラウザーを再読み込みします。再起動で一時URLが変わった場合は、新しいURLで開いてください。

Cloudflare Workers / D1に直接配置する場合は、既存のSQLに続けて drizzle/0003_calendar.sql を適用してください。

## URLについて

固定URL用の `start-sns.cmd` はngrokを使います。初回設定後、同じアカウント・ドメイン設定なら再起動後も同じURLでアクセスします。詳細は [FIXED_URL.md](FIXED_URL.md) を参照してください。従来の `start-external.ps1` を使った場合はCloudflareの一時URLとなり、再起動時に変わります。

## 検証

予定追加の管理者制限、他人の予定の変更・削除拒否、入力検証、月の絞り込み、従来データを保持した移行、再起動後の保存を自動テストしています。今回の権限変更・固定コメントの操作は [ADMIN_FEATURES.md](ADMIN_FEATURES.md) を参照してください。
