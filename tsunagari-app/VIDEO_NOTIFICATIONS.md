# 動画投稿とアプリ通知

## 短い動画を投稿する

投稿欄の「動画」から選び、プレビューを確認して「投稿する」を押します。

- MP4形式、60秒以内、20MB以内、1投稿につき1本です。H.264映像・AAC音声のMP4を推奨します。
- 動画だけでも、本文を添えても投稿できます。写真・スタンプと動画は別の投稿にしてください。
- 長さとサイズを超える場合は、端末の動画編集アプリで短く・小さくしてから投稿してください。自動変換・圧縮・トリミング機能はありません。
- MOVなど、MP4以外はMP4形式で書き出してください。MP4でも端末に対応していないコーデックは再生できない場合があります。
- タイムラインの再生ボタンで視聴できます。自動再生はしません。「写真のある投稿」には動画を含めません。
- 動画はログインしたメンバーだけが取得できます。投稿を削除すると動画ファイルも削除します。

動画は `data-external-trial/media` に保存します。保存先を変更している場合は、その中の `media` です。動画は画像より通信量が増えるため、ngrokの利用状況も確認してください。

## iPhoneのホーム画面に追加する

1. Safariで、設定済みのSNSの固定URLを開く。
2. Safariの共有ボタン →「ホーム画面に追加」を選ぶ。「Webアプリとして開く」があればオンにする。
3. 追加された「つながり」のアイコンから起動し、SNSのID・パスワードでログインする。
4. 自分のプロフィール →「通知設定」→「通知をオンにする」を押し、iPhoneの確認で「許可」を選ぶ。
5. 「テスト通知」を押し、送信結果と通知が届くかを確認する。登録が古い場合は「通知を登録し直す」を押す。

テスト通知は操作した端末だけが対象です。「通知サービスが受け付けました」はサービスの受付までの確認で、端末に表示されたことを示しません。自分で投稿した内容は自分には通知されないため、「テスト通知」または他のメンバーの投稿で確認してください。更新版の見分け方とエラーごとの対処は [MOBILE.md](MOBILE.md) にあります。

iPhone / iPadの通知にはiOS / iPadOS 16.4以降が必要です。Safariの通常のタブではなく、ホーム画面のアイコンから開いて設定してください。App Storeで配布するネイティブアプリではありません。Apple Developer Programへの加入は不要です。

PCの対応ブラウザーでも、プロフィールの「通知設定」から許可できます。今回の実装はApple Web Push、Google FCM、Mozillaの通知先に対応しています。

## 通知される内容

通知をオンにした端末へ、次の操作を通知します。

| 操作 | 通知する相手 |
|---|---|
| 新しい投稿（文字・画像・動画） | 通知をオンにしている他のメンバー |
| 投稿への返信コメント | その投稿の作成者（自分自身への返信を除く） |
| 管理者が固定コメントを保存 | 通知をオンにしている他のメンバー。空欄で解除した場合を除く |

通知には投稿者の名前と本文の冒頭100文字を表示し、画像・動画があれば添付情報も文字で表示します。投稿・返信の通知を押すと対象の投稿を開き、固定コメントとテスト通知ではホームを開きます。長文は末尾を「…」に省略します。端末の設定によってはロック画面にも名前と本文が表示されます。以前の通知登録は、通知設定で「通知をオンにする」を押すまで従来の一般的なお知らせになります。詳しくは [NOTIFICATION_CONTENT.md](NOTIFICATION_CONTENT.md) を参照してください。いいね、削除、カレンダー変更は通知対象外です。

端末ごとの「通知をオフにする」で停止できます。通知の許可は自分でボタンを押したときだけ求めます。

## 通知の条件

- サーバーPC、SNS、ネット接続が動いている必要があります。利用者がSNSの画面を閉じていても、OS・ブラウザーの通知機能で受信できます。
- 通知はログイン中の端末にひもづきます。ログアウト、7日間のログイン期限切れ、パスワード変更、管理者による利用停止で、該当セッション宛ての送信を止めます。再ログイン後は「通知をオンにする」を押してください。
- 端末の集中モードや通知設定、回線、通知サービスの状態によって、表示が遅れたり届かなかったりする場合があります。送信済みの通知はオフにした直後に届く場合もあります。
- 送信待ちは5分間保持し、一時エラーは最大3回試行します。通知の完全な到着保証・過去通知の再送機能はありません。
- 通知を拒否した場合は、端末・ブラウザーの設定から許可に変更してください。
- 固定URLを変更した場合はホーム画面への追加・通知設定もやり直してください。

## 更新する

1. SNSを `Ctrl+C` で停止する。
2. `data-external-trial` を丸ごとバックアップする。
3. 更新ZIPの `tsunagari-app` 内を、これまで使っている同名フォルダーに上書きする。既存の `data-external-trial` と `.sns-private` は残す。
4. `start-sns.cmd` で固定URLのSNSを起動する。
5. ブラウザー・ホーム画面のアプリを開き直す。古い画面が残る場合は再読み込みする。

Node.js版は通知用テーブルと通知用の鍵を自動で用意します。追加ソフト・npm install・通知サービスのアカウント登録は不要です。通知の許可だけは各利用者が自分の端末で設定します。

通知用の鍵 `push-keys.json` と認証キャッシュ `push-authorization.json` はデータフォルダー内に保存します。データフォルダーと一緒にバックアップし、公開・Git登録しないでください。鍵を削除すると端末の通知登録が使えなくなるため、削除しないでください。

通知送信はNode.js版のHTTPS構成で動作します。Cloudflare Workers / D1へ直接配置する構成では `drizzle/0005_push.sql` と `drizzle/0006_push_content.sql` を適用しても送信処理は動きません。別途送信基盤が必要です。今回の固定URLで起動する構成はNode.js版なので対象です。

## 確認状況

動画の形式・長さ・サイズ制限、認証、部分取得によるシーク、投稿削除時の動画削除、通知の登録・解除・対象者選択・セッション失効・署名・再試行・保存を自動テストしています。通知サービスへの送信はテスト用の応答に置き換えて検証しています。実サービス経由の配信、動画の実際のデコード、iPhone実機の再生・通知到着は、この環境では未確認です。更新後に短いMP4の投稿と「テスト通知」で確認してください。
