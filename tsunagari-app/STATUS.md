# 現在の状態

GitHubにはアプリのソースコード、起動ファイル、説明書、自動テストを収録しています。

- 招待制の専用ID・パスワードによるログイン（ChatGPTログイン不要）
- 文字・画像・短い動画の投稿、いいね、返信、検索、トピック
- プロフィール編集、共有カレンダー、管理者の固定コメント
- スマホのホーム画面への追加と、投稿者名・本文を表示する通知
- Windows PCからngrokの固定URLで公開する構成
- 通報、管理者による投稿・返信の非表示・削除、操作履歴、保存期間（初期設定は無期限）
- 毎日の自動バックアップ・手動保存・別フォルダーへの復元
- 操作履歴、管理者向け稼働監視・処理エラー表示
- 自動テスト46件に合格

GitHubへのコード掲載だけではSNSサーバーは起動しません。設定と起動は [FIXED_URL.md](FIXED_URL.md)、初期登録は [HOME_SERVER.md](HOME_SERVER.md) を参照してください。実際の端末での動作は更新後に確認してください。
