# スマホ画面と通知の確認

## 2026年11月23日の変更

- 入力欄を16px以上にし、iPhoneで投稿・返信・検索などの入力時に起こる自動拡大を抑えました。指での拡大操作は利用できます。
- 画面右下の紫色の雲と「＋」が、投稿欄を開くボタンです。文字入力中は隠れます。
- 下部メニューの「投稿」を「トピック」に変更しました。「日々のこと」「仕事のヒント」「お知らせ」「ありがとう」から投稿を絞り込めます。「すべてのトピック」で解除します。検索キーワードがある場合は組み合わせて絞り込みます。
- 投稿欄の「投稿する」は、内容を送信するために残しています。
- 通知登録と現在の端末・通知用の鍵を照合します。「通知を登録し直す」で登録を更新できます。
- テスト通知は操作した端末だけに送り、通知サービスの応答を画面に表示します。サービスの受付と、端末への表示は別です。

名前と本文を表示する通知は [NOTIFICATION_CONTENT.md](NOTIFICATION_CONTENT.md) を参照してください。

## 更新と通知の確認

1. サーバーの起動画面で `Ctrl+C` を押して停止します。
2. 今使っている `data-external-trial` と `.sns-private` をバックアップします。
3. ZIPを展開し、`tsunagari-app` 内のファイルを今使っている同名フォルダーへ上書きします。既存のデータ・設定フォルダーは残してください。
4. 上書きしたフォルダーの `start-sns.cmd` を起動します。古いコピーを指すショートカットには注意してください。
5. スマホのホーム画面からアプリを開き直します。下部に「トピック」、右下に雲の投稿ボタンがあることを確認します。
6. 「自分」→「通知設定」を開き、「更新版 2026.11.23」と表示されていることを確認します。
7. 「通知をオンにする」または「通知を登録し直す」を押して許可し、「テスト通知」を押します。

自分が投稿した内容は自分には通知しません。他のメンバーの投稿か、「テスト通知」で確認してください。iPhoneではホーム画面に追加したアプリで設定します。通知にはiOS 16.4以降が必要です。

| テスト結果 | 確認すること |
|---|---|
| 通知サービスが受け付けました | ホーム画面に戻り、通知センターも確認。届かなければ端末の通知許可、集中モードを確認 |
| 登録がない・期限切れ | 「通知を登録し直す」を押して再テスト |
| 認証エラー | 登録し直して再テスト。続く場合は表示されたHTTP番号を管理者に伝える |
| 通知サービスに接続できない | サーバーPCのインターネット接続・通信制限を確認 |
| サーバー側の通知が利用できない | 新版をHTTPSの固定URLで起動しているか、データ保存先に書き込めるかを確認 |

通知の対象・運用条件は [VIDEO_NOTIFICATIONS.md](VIDEO_NOTIFICATIONS.md) を参照してください。自動テストでは送信先を模擬して成功・認証エラー・期限切れ等を確認しています。実際のiPhoneでの表示・通知到着は更新後に確認してください。
