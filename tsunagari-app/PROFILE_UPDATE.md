# プロフィール編集

プロフィール画像、ヘッダー画像、表示名、自己紹介、場所を編集できます。部署の入力欄・表示はありません。

## 編集する

1. PCでは自分のアイコン、iPhoneでは下部の「自分」を押します。
2. 「プロフィールを編集」を押します。
3. 内容や画像を変更して「保存」を押します。

| 項目 | 条件 |
|---|---|
| 表示名 | 必須・40文字以内 |
| 自己紹介 | 任意・160文字以内 |
| 場所 | 任意・30文字以内 |
| アイコン | JPEG・PNG・WebP。中央を正方形に切り抜いて保存 |
| ヘッダー | JPEG・PNG・WebP。中央を横3：縦1に切り抜いて保存 |

ブラウザーで読み込める画像を選んでください。元画像は25MB以内、保存する画像は1枚3MB以内です。画像は「削除」で初期表示に戻せます。変更は「保存」を押した後に反映されます。ログインIDはプロフィール編集では変更しません。

プロフィールと画像はログイン済みのメンバーが閲覧できます。投稿やコメントの名前・アイコンからプロフィールを開けます。

## 更新する

1. 起動中のSNSを `Ctrl+C` で停止します。
2. 念のため、既存の `data-external-trial` フォルダーを別の場所にコピーしておきます。
3. 更新ZIPを展開し、`tsunagari-app` の中身を、これまで使っていた同名フォルダーに上書きコピーします。既存のデータフォルダーを削除しないでください。
4. `start-sns.cmd` をダブルクリックします。

Node.js版では起動時に必要なデータベース項目が自動追加されます。アカウントと投稿は引き継がれます。旧バージョンの部署データは互換性のため内部に残りますが、画面やプロフィールAPIには出しません。

Cloudflare Workers/D1へ別途配置している場合は、公開前に `0002_profile_details.sql` のマイグレーションも適用してください。
