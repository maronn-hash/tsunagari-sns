# 返信コメント・カレンダー・固定コメント

## 返信コメントを削除する

投稿の「コメント」を開くと、自分が書いた返信に「削除」が表示されます。確認画面で「削除する」を押すと、その返信だけが消え、投稿のコメント件数も更新されます。他の人の返信は削除できません。削除は元に戻せません。

## カレンダーの予定追加

予定を新しく追加できるのは管理者だけです。一般メンバーには「予定を追加」を表示しません。ログインしたメンバー全員が予定を閲覧できます。編集・削除は従来どおり登録者本人だけです。更新前に一般メンバーが作った予定も残り、その本人が編集・削除できます。

## ホームの固定コメント

「何気ないひとことが、チームを近くする。」「今日の発見も、ちょっとした『ありがとう』も。」があったホーム上部を、固定コメント欄に置き換えました。

1. 管理者でログインする。
2. ホーム上部の「固定コメントを追加」を押す。
3. 伝えたい内容を入力し「保存する」を押す。

固定コメントは1件・1000文字以内で、改行できます。ログインしたメンバー全員のホームに表示されます。管理者は「編集する」から変更でき、空欄で保存すると解除できます。未設定・解除時は一般メンバーには欄自体を表示しません。「自分の投稿」「いいねした投稿」には表示しません。ほかのメンバーの画面には、ページ再読み込みまたはホーム右上の更新ボタンで反映されます。HTMLは文字として表示します。

## 更新手順

1. 起動画面で `Ctrl+C` を押してSNSを停止する。
2. 既存の `data-external-trial` フォルダーを丸ごとバックアップする。保存先を変更している場合はそのフォルダーを使う。
3. 更新ZIPの `tsunagari-app` 内のファイルを、これまで使っているアプリフォルダーに上書きする。`data-external-trial` と固定URLの設定フォルダー `.sns-private` は残す。
4. `start-sns.cmd` で起動し、ブラウザーを再読み込みする。

固定URLの設定はそのまま使えます。Node.js版は必要なテーブルを自動追加し、既存のアカウント・投稿・画像・返信・予定を引き継ぎます。Cloudflare Workers / D1へ直接配置する構成では、既存マイグレーションに続けて `drizzle/0004_announcement.sql` を適用してください。

## 検証範囲

自動テストで、返信の削除権限・削除後の件数、予定追加の管理者制限、固定コメントの閲覧・編集権限、入力検証、更新前のデータ維持と再起動後の保存を確認します。画面のボタン表示・確認操作・固定コメントの文字表示もテスト対象です。今回の変更についてブラウザーの外観・iPhone実機での確認は未実施です。
