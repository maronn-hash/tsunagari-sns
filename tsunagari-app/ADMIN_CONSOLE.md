# 別タブで使う管理画面

管理者用の操作を、通常のSNSから独立した **`/admin`** ページにまとめました。同じSNSサーバー・DBを利用するため、新しいサーバーや別アカウントを用意する必要はありません。

## 開き方

1. 管理者でSNSにログインします。
2. 自分のプロフィールから「管理画面を開く ↗」を押します。
3. 新しいタブに管理画面が開きます。

固定URLの末尾に `/admin` を付けて直接開くこともできます。

```text
SNS:    https://あなたの固定URL/
管理:   https://あなたの固定URL/admin
```

通常のSNSをChrome、管理画面をEdgeなど、別のブラウザーで開いても利用できます。別ブラウザーでは、管理画面のログインフォームで既存の管理者ID・パスワードを入力します。最初の管理者登録は従来どおりSNS側で行います。

## 管理画面のメニュー

| メニュー | 操作 |
| --- | --- |
| メンバー管理 | 招待コード発行、利用停止・再開 |
| 投稿・通報の管理 | 通報確認、投稿・返信の非表示・再表示・削除、保存期間、対応履歴 |
| バックアップ・監視 | 手動・自動バックアップ、保存世代、稼働状況・システム記録 |
| 操作履歴 | ログインや管理操作の成功・失敗を確認 |
| 固定コメント | SNSのホームに表示するお知らせを編集 |
| 共有カレンダー | 予定の追加、登録した予定の編集・削除 |

通常のSNSの投稿・返信にある「管理 ↗」からも、対象を選択した状態で別タブの管理画面を開けます。固定コメントの編集や管理者による予定の操作も管理画面へ移動します。一般メンバーの「通報」はSNS内から利用できます。

予定の編集・削除は従来どおり登録者本人のみです。過去に一般メンバーが登録した予定は、その本人がSNS側で編集できます。

## ログインとアクセス権限

- 同じブラウザーではSNSと管理画面のログイン状態を共有します。片方でログアウトすると両方がログアウトします。対応ブラウザーではタブ間に変更を通知して画面を更新します。
- 別ブラウザーでは別のログインセッションです。それぞれログイン・ログアウトできます。
- 未ログインでは管理者ログイン画面を表示します。一般メンバーでは管理メニュー・管理データを表示せず、管理APIでも権限を確認します。
- ログイン画面や画面用のHTML・JavaScript自体は公開されますが、メンバー情報・バックアップ状況などのデータは管理者認証後に取得します。
- 管理画面を再び操作対象にした際にも、ログイン状態を確認します。期限切れや利用停止が確認された場合は管理内容を消してログイン画面に戻ります。

## 更新手順

1. SNSを停止し、既存のデータをバックアップします。
2. 更新版の `tsunagari-app` 内を、利用中のアプリフォルダーに上書きします。
3. `data-external-trial`、`.sns-private`、バックアップ保存先は残します。
4. `start-sns.cmd` で起動し、SNSを再読み込みします。
5. 管理者のプロフィール →「管理画面を開く」から確認します。

固定URL、アカウント、投稿、既存のバックアップ設定をそのまま使います。この変更ではDBの移行は追加していません。

## 確認範囲

自動テストで管理画面の配信、管理権限、共有スクリプトの初期化、一般メンバーのアクセス制限、文字のエスケープ、ログアウト後の応答破棄、通常のSNSからの通報を確認します。テスト環境のブラウザー実行ファイルが欠けていたため、ブラウザーの外観・別タブの実操作・スマホ実機での確認は未実施です。
